# Meko

واجهة أولية لتطبيق غرف صوتية اجتماعية باستخدام Flutter.

## الموجود حالياً
- شاشة رئيسية باسم Meko
- غرف صوتية تجريبية
- إنشاء غرفة
- شاشة غرفة صوتية
- كتم/إلغاء كتم واجهة الميكروفون
- هدية وخروج ومشاركة كواجهات أولية
- تبويبات الرئيسية / اكتشف / حسابي
- codemagic.yaml جاهز لبناء Android

## تشغيل المشروع
بعد تثبيت Flutter:

    flutter pub get
    flutter create --org com.meko --project-name meko .
    flutter run

## ملاحظة
الصوت الحقيقي، تسجيل الحسابات، قاعدة البيانات، الهدايا، الدردشة، الإشراف، والخادم غير موصولة بعد. هذه نسخة واجهة/Prototype قابلة للتطوير.
